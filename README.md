# Poongodi Farm 🌾

A full-stack farm management application for **பூங்கொடி இயற்கை பண்ணை (Poongodi Natural Farm)**.

## Features
- 🔐 Login with Email or Google Account
- 🏠 Dashboard with today's farm stats
- ➕ Add daily farm data (eggs, meat, expenses)
- 📅 History of all records
- 📊 Reports with total sales, expenses & profit/loss
- 💾 SQLite database for persistent storage

## Tech Stack
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** SQLite3

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Server
```bash
node server.js
```

### 3. Open in Browser
Navigate to: [http://localhost:3000](http://localhost:3000)
